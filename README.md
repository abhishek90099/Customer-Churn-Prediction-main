# Customer Churn Prediction

ML-based customer churn prediction using AdaBoost, with a trained model (.pkl) and a Flask app for serving predictions.

## Contents
- `Customer churn prediction.ipynb` — model training/EDA notebook
- `app.py` — Flask web app for serving predictions
- `model.pkl` / `adaboost_churn_model.pkl` — trained models
- `customer_churn.csv` — dataset
- `ML.pdf`, `CUSTOMER CHURN PREDICTION_VideolinkFINAL.pdf` — project report / presentation

## Run locally
```
pip install flask scikit-learn pandas
python app.py
```
